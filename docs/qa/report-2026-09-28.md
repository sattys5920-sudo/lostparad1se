## 2. 도구

- **개발용 시계**: `setDevClock` (운영자) ×1~×240 + 시간 점프(ClockDesk). 서버는 `nowOf(game)`, 화면은 `useGameNow(clock)` + 기기 시계 보정(skew.ts).
- **Date.now() 전수 조사** — 게임 상태를 판단하는 곳은 전부 게임 시계다. 남겨 둔 실제 시각 사용(의도적):
  - 오락실 실시간 미니게임(arcade.ts · arcadeTime.ts — 반응 속도는 실제 시간이라야 한다)
  - 알림 조용한 시간 00–08(notify.ts — 사람의 밤은 실제 밤이다), 웹 푸시 구독 시각, 읽음 시각
  - 계정 만든 시각, 판 seed, 운영자 코드 입력 간격(hostgate.ts), 실기록 스탬프(missionDays 보냄 시각, ending 적은 시각)
  - 화면 제스처(탭 간격·스와이프·연출), 실시간 위치 신선도(Walk.tsx live), 무전 스파이크 연출
  - 시작 전 로비의 Walk(nowMs) — 게임 시계가 아직 없다
- **봇 14명**: `scripts/qa-bots.ts` — 성향 열심히/보통/하루 한 번 접속/중간 이탈, 실제 API 호출, `OUT/{TAG}/events.jsonl · invariants.jsonl · mem.jsonl · summary.json`. 옵션 SPEED · DAYS · ABSENT(운영자 늦게 달력 넘김) · PAUSE=day:hour:hours(멈춤) · MANUAL_CLOSE.
- **이벤트 로그 뷰어**: 운영자 「로그」 탭(EventLog.tsx) — 페이즈·정산·투표·미션·알림·비밀 기록을 한 줄에 하나로, 사람·종류로 걸러 보고, 따라가기, JSON 내려받기. 채팅 본문·역할·득표 대상은 안 나간다.
- **불변 조건**: `checkInvariants` — 페이즈가 닫힐 때마다(closePhaseNow) 판을 훑어 `secret/qa/violations` 에 남기고, 운영자 「로그」 탭 위에 붉게 띄운다. 조건: 자리 없는 말·방 없는 말·칸-방 불일치·한 칸에 둘·설 수 없는 칸·금고 음수·토큰 음수·팀/방 로봇 한도·쪽지 수·방 주인 값.

## 10. 열린 질문 (규칙 결정이 필요)

1. **방 주인은 깃발·로봇으로 정한다** — 요청 문구는 「방마다 사람 수를 세어 …」. 현재 코드·문서(깃발 점령)는 깃발 수. 어느 쪽이 맞나?
2. **「같은 칸에 서면」 행동** — 한 칸에 한 명이라 같은 칸은 불가능. 지금은 **옆 칸**(거래·쪽지 주기)이거나 **같은 방**(표 주기). 그대로 둘까?
3. 복도에 선 사람의 tileId 가 앞 방으로 남는다(#9). 사람 수 기준으로 바꾼다면 복도를 「어느 방도 아님」으로 세야 한다.
4. 소등은 이미 없다(자유 시간 24시간). 문구만 남은 곳이 있으면 지운다.

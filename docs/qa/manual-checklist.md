# 실기기 수동 점검표 — 투명인간

자동 시험이 못 보는 것만 모았다. 폰 둘(iOS Safari 홈 화면 추가 · Android Chrome)과
PC 브라우저 하나로 본다. 한 줄에 하나씩, 되면 ✅ 안 되면 증상을 적는다.

같은 계정을 두 기기에서 동시에 열어 두고 시작한다(「같은 계정 두 기기」 항목이 이걸 본다).

## A. 들어오기 · 자리

| # | 할 일 | 기대 | 결과 |
|---|---|---|---|
| A1 | 시작 전에 로그인해 2-3 교실에 들어간다 | 열넷이 한 칸에 한 명씩, 겹치지 않는다 | |
| A2 | 시작 전에 다른 방으로 걸어 나가 본다 | 「지금은 할 수 없다」— 교실 밖으로 못 나간다 | |
| A3 | 운영자가 시작을 누른다 | 폰 둘 다 몇 초 안에 자유 시간 화면으로 바뀐다 | |
| A4 | 폰 시계를 10분 빠르게 맞추고 페이즈를 연다 | 타이머가 서버와 같은 시각에 0을 찍는다(10분 먼저 끝나지 않는다) | |
| A5 | 폰 시계를 10분 느리게 맞춘다 | 페이즈가 끝나면 즉시 「지금은 페이즈가 아니다」— 화면이 끝났다고 보여 준다 | |

## B. 끊김 · 복귀

| # | 할 일 | 기대 | 결과 |
|---|---|---|---|
| B1 | 페이즈 중에 화면을 끄고 30분 뒤 켠다 | 남은 시간이 맞게 보이고, 위치·토큰이 서버와 같다 | |
| B2 | 비행기 모드로 두고 이동 버튼을 누른다 | 「연결을 기다리는 중이다」 — 쌓여 있다가 한꺼번에 나가지 않는다 | |
| B3 | 비행기 모드를 풀고 2분 기다린다 | 자동으로 다시 붙고 채팅·위치가 따라온다. 새로고침 없이 | |
| B4 | 걷는 중에 앱을 죽이고 다시 연다 | 도착해 있거나 걷는 중 그대로. 두 방에 동시에 있지 않다 | |
| B5 | 같은 계정을 두 기기에서 연다 | 한 기기에서 움직이면 다른 기기도 따라온다. 서로 다른 방에 서 있지 않다 | |
| B6 | 자정을 넘기는 동안 아무도 접속하지 않는다(운영자도) | 아침에 첫 접속이 하루 판정·투표 집계를 한 번에 끌어온다. 두 번 판정되지 않는다 | |
| B7 | 채팅을 치다 방을 나갔다가 다시 들어온다 | 아까 보던 채팅이 사라지고, 다시 들어온 시각부터만 보인다 | |

## C. 폰마다 다른 것

| # | 할 일 | 기대 | 결과 |
|---|---|---|---|
| C1 | iOS 홈 화면 추가(PWA)로 열고 알림을 켠다 | 권한 창이 뜨고, 운영자 공지가 잠금 화면에 온다 | |
| C2 | Android Chrome 에서 알림을 켠다 | 같은 결과 | |

| C6 | 화면을 두 손가락으로 벌린다 | 최대 2배까지만 커진다 | |
| C7 | PC 브라우저(1280px)로 본다 | 캐릭터 크기가 폰과 같은 비율(2배 상한)이다 | |

## D. 하루 흐름(운영자 폰 하나 + 참가자 폰 하나)

| D2 | 열고 50분에 운영자가 닫는다 | 즉시 닫히고 참가자 화면이 자유 시간으로 바뀐다 | |

| D8 | 나흘째 24시 | 「마지막 선택」과 엔딩이 열린다. 더는 아무것도 못 한다 | |

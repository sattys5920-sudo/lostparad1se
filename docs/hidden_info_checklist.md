# 숨긴 정보 점검표

> 받은 뒤 화면에서 숨기는 방식은 쓰지 않는다. 개발자도구로 보이면 게임이 망가진다.
> 숨겨야 할 값은 **클라이언트로 보내는 문서에 애초에 들어가지 않는다.**

기준 문서 두 개(`team_rules_v2.md`, `personal_missions_v2.md`)가 「숨긴다」고 말한 것을
전부 적고, 어디에 저장되고 무엇이 막는지를 짝지었다.

---

## 1. 문서가 놓이는 자리

```
games/{gameId}                    공개. 누구나 읽는다
  ├─ tiles/{tileId}               공개 — 주인·건물·방어
  ├─ flags/{tileId}               공개 — 깃발은 시끄럽다. 가짜도 진짜와 같은 모양
  ├─ teams/{teamId}               공개 — 자원·연구 단계·손패 장수·주장·공개 점수
  ├─ events/{eventId}             공개 — 일어난 일
  ├─ pawns/{playerId}             읽기 금지  ← 안개
  ├─ schedule/{id}                읽기 금지  ← 등교 예약
  ├─ secret/**                    읽기 금지  ← 서버만
  └─ views/{playerId}             본인만 읽는다. 서버가 걸러 만든다
```

`firestore.rules`가 `pawns`·`schedule`·`secret`에 `allow read: if false`를 건다.
규칙을 통과하는 읽기 경로가 없으므로, 클라이언트 코드가 어떻게 짜여 있든 값이 나가지 않는다.

## 2. 항목별

| 숨겨야 할 것 | 어디에 있나 | 무엇이 막나 | 시험 |
|---|---|---|---|
| 안개 속 말의 위치 | `pawns/**` (읽기 금지) | 규칙 + `visiblePawns()`가 view를 만들 때 아예 빼고 담는다 | `fog.test.ts` 「보이는 말」 |
| 걷는 말의 목적지 | 서버 메모리 | `walkPositionAt()`이 **다음 칸까지만** 돌려준다. `PawnView`에 목적지 자리가 없다 | `fog.test.ts` 「어느 view에도 목적지가 들어 있지 않다」 |
| 잠복 중인 말 | `pawns/**` | `visiblePawns()`가 목록에서 뺀다. 같은 팀에게도(규칙 원문 「누구에게도」) | `fog.test.ts` 「잠복한 말은 …안 보인다」 |
| 등교 예약 | `schedule/**` (읽기 금지) | 규칙. 08:00에 걸음으로 바뀐 뒤에야 안개 규칙대로 드러난다 | — |
| 표를 보낸 사람 | `secret/votes/**` | `tallyVotes()`가 팀 합계만 만든다. 결과 객체에 `voterId`가 없다 | `votes.test.ts` 「합계에는 보낸 사람이 들어 있지 않다」 |
| 가짜 깃발 여부 | `secret/flagTruth/**` | `flags/{tileId}`에는 진짜와 **똑같은 모양**으로 놓인다. 네트워크 응답으로도 구분되지 않는다 | `model.ts` 주석 · 규칙 |
| 팀 손패 내용 | `secret/cards/**` | `teams/{teamId}`에는 `handCount`(장수)만 있다 | — |
| 비밀 목표 | `secret/goals/**` | DAY 3에 고른 한 장만 공개 문서로 옮긴다 | — |
| 남의 역할 | `secret/roles/**` | 종료 전에는 어떤 API도 남의 역할을 돌려주지 않는다. `ownAssignment()`가 자기 한 줄만 꺼낸다 | `judge.test.ts` 「남의 아이디가 하나도 없다」 |
| 내 인연 대상이 누구인지 | `secret/roles/**` | 미션 글이 「인연 대상」이라고만 적는다. view에 `bondId`가 없다 | `judge.test.ts` 「인연 대상 아이디가 없다」 |
| 진행 중 미션 진행도 | 서버 계산 | `discloseFor()`가 `disclosure`에 따라 값을 **빼고** 만든다(`have: null`) | `judge.test.ts` 「공개 정책」 |
| 고발자의 적중 여부 | 서버 계산 | `hidden` — 종료 전 어느 단계에서도 숫자가 나가지 않는다 | `judge.test.ts` 「고발자의 적중은 …」 |
| 최종 점수·엔딩 | 서버 계산 | `phase !== 'end'`면 `score: null, bandId: null` | `judge.test.ts` 「끝나기 전에는 …」 |
| 비밀 목표 점수 | 서버 계산 | `publicScore()`는 `goals: 0`을 고정으로 낸다. `finalScore()`만 더한다 | `score.test.ts` 「공개 점수와 최종 점수」 |

## 3. 진행도 공개 정책이 익명 표를 지키는 법

개인 미션 조항 중 **받은 표**에 걸린 것은 실시간으로 보여 주지 않는다.
실시간이면 "방금 숫자가 올랐다 → 조금 전에 나갔던 그 사람이다"로 역추적된다.

| 단계 | 언제 열리나 | 예 |
|---|---|---|
| `realtime` | 바로 | 내 행동으로만 정해지는 것 — 방어 참여, 탐색 횟수, 방문한 칸 |
| `settlement` | 21:00 정산 때만 갱신 | 받은 신뢰표 수, 받은 의심표 수 |
| `endOnly` | 종료 후 | 보낸 사람이 특정되는 것, 남의 순위·소유·동맹 |
| `hidden` | 종료 후 (진행 중 표시 자체가 없음) | 고발자의 적중·헛짚음 |

`roles.test.ts`가 이 배치를 데이터에서 직접 확인한다 — 새 조항을 넣을 때
`disclosure`를 잘못 달면 시험이 막는다.

---

## 4. 판정에 쓰지 않는 것

- **채팅에 손으로 친 말.** 어떤 판정에도 쓰이지 않는다. "나 털어놓을게"라고
  쓰는 것과 실제로 털어놓는 것은 다른 일이다. 털어놓기는 「공인된 고백」
  시스템 카드로만 성립한다.
- **교역 제안에 덧붙인 말.** 자원 계산에 들어가지 않는다
  (`diplomacy.test.ts` 「덧붙인 말은 계산에 들어가지 않는다」).

---

## 5. 아직 남은 것

- `firestore.rules`는 **콘솔에 직접 붙여넣어야** 적용된다. CI가 배포하지 않는다.
- 본인 확인은 Firebase Auth의 `request.auth.uid`로 한다. 클라이언트 쪽
  비밀번호 검사로 대신하지 않는다.
- 운영자 전용 조회 화면은 서버 인증(커스텀 클레임)을 거친다.

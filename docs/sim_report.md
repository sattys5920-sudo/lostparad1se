# 봇 100판 보고서

`npm run sim` — 씨앗이 고정이라 코드가 같으면 숫자도 같다. 규칙을 고친 뒤
다시 돌려서 무엇이 움직였는지 본다.

## 이 숫자를 어떻게 읽어야 하나

봇은 **말을 하지 않는다.** 짜고 움직이지 않고, 약속하지 않고, 자기 인연이
누구인지 보지도 않는다. 그래서 이 표는 「사람이 하면 이쯤 된다」가 아니라
**바닥**이다.

- 달성률이 0%에 가깝다 → 그 미션은 말과 협력이 있어야 깨진다. 정상일 수 있다.
- 달성률이 100%에 가깝다 → **아무 생각 없이 움직여도 깨진다.** 이건 문제다.

또 하나, 시뮬레이션의 한계를 먼저 적어 둔다.

- **교역을 상대가 무조건 받아들인다.** 실제로는 상대가 수락해야 성립한다.
  교역이 걸린 조항(중재자 주 미션, 도서부 인연)의 달성률은 그만큼 부풀어 있다.
- **DAY 3 중요한 사람 · DAY 4 선택 · 종례 동석을 봇이 하지 않는다.**
  9점 중 4점이 통째로 빠져 있어, 이 판에서 나올 수 있는 최고점은 5점이다.

## 100판 결과

### 판이 기울어 있지 않다

```
우승      A 25   B 20   C 25   D 30
팀 점수   최저 20 · 평균 51.0 · 최고 89
```

네 팀이 고르게 이긴다. 3인 팀(C·D)이 4인 팀(A·B)에 밀리지 않는다 —
행동 토큰이 인원과 무관하게 같고, 주장이 머릿수를 메우기 때문이다.
판이 90도 회전 대칭이라는 구조도 `board.test.ts`가 좌표에서 따로 확인한다.

### 판이 얼어붙지 않는다

```
한 판 평균   깃발 34.5 꽂아 20.5 성공 (59%)
             표 70.0 · 털어놓기 13.1 · 건물 30.1
```

표 70은 상한(14명 × 5일)에 딱 닿는다 — 하루 한 장 제한이 제대로 걸린다.
깃발이 서른 번 넘게 오가고 서른 채가 올라가므로, 닷새가 비어 있지 않다.

### 개인 점수

```
0점  832   ████████████████████████████████████
2점  258   ███████████
3점  236   ██████████
5점   74   ███
평균 1.14
```

봇이 손대지 않는 4점이 빠진 채의 분포다. 0점이 59%인 것은 「말 없이는
아무것도 안 된다」는 설계 의도와 같은 방향이다.

## 손봐야 할 곳 — 판단은 사람이 한다

세 가지를 올린다. **고치지 않았다.** 규칙 문서가 기준이고, 문서를 바꾸는
것은 만든 사람의 몫이다.

1. **전학생 주 미션이 공짜에 가깝다(78%).** 「서로 다른 칸 15곳 방문 + 탐색
   3회」는 목적 없이 걸어 다니기만 해도 채워진다. 15를 20으로 올리거나
   「각각 30분 이상 머문 칸」으로 바꾸면 의도한 난이도에 가까워진다.

2. **중재자·도서부는 다시 재야 한다.** 교역 수락 모형이 비현실적이라
   99%가 신뢰할 수 없는 숫자다. 봇에 수락 판단을 넣은 뒤 다시 돌리는 게
   먼저다.

3. **수첩(12%)은 털어놓기 상한 6이 들어오면서 확실히 어려워졌다.**
   두 번째부터의 1:1은 말하는 쪽에 순수하게 손해라, 「서로 다른 2명에게서
   1:1을 듣는다」를 채워 줄 사람이 줄었다. 이건 상한 규칙의 **의도된**
   결과일 수도 있다 — 그래서 건드리지 않았다.

0%가 찍힌 역할들(방관자·편지·그림자)은 전부 **말과 약속이 있어야 깨지는**
미션이다. 봇이 못 깨는 게 당연하고, 그 자체로는 고칠 이유가 아니다.
